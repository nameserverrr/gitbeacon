# gitbeacon
A lightweight API for exposing Git repository metadata, including the current branch, commit hash, version, commit message, and build information, making it easy to display project version details directly in your apps.

# ✨ Features 
- Current Git branch
- Commit hash / SHA
- Latest commit message
- Project version
- Commit timestamp
- Build and deployment metadata
- Lightweight and easy to integrate
- Written entirely in TypeScript

**Please note this is an all-in-one file project. I do not have the motivation to make this a full thing**
